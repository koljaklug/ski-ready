# Ski Ready

A private, mobile-first ski-prep tracker that works offline after its first visit. Training history and the personalized rep targets are stored only in the browser on the device.

## Use it on iPhone

Deploy this folder with GitHub Pages, open its HTTPS address in Safari, then use **Share → Add to Home Screen**. It will open without browser chrome and continue to work offline.

## GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. In the repository settings, enable **Pages** and deploy from the `main` branch, root folder.
3. Visit the resulting link on the iPhone in Safari.

No account, server, or health data upload is required.

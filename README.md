# Ski Ready

A mobile-first ski-prep tracker that works offline after its first visit. Training history and the personalized rep targets are stored only in the browser on the device.

## Use it on iPhone

Open [Ski Ready in Safari](https://koljaklug.github.io/ski-ready/), then use **Share → Add to Home Screen**. It will open without browser chrome and continue to work offline.

## GitHub Pages

The app is published through GitHub Pages from the `main` branch. Its public Safari address is:

`https://koljaklug.github.io/ski-ready/`

No account, server, or health data upload is required.
